## ✨ Overview

**Evently** is a full-stack, production-grade event management platform built for one of Hyderabad's premier event planning companies. The platform provides an immersive digital experience for clients looking to plan weddings, birthday celebrations, and corporate events.

With over a decade of industry excellence, Evently Events has orchestrated hundreds of dream celebrations across Telangana and Andhra Pradesh. This website is the company's digital gateway — offering seamless service exploration, an interactive event planner, a rich gallery portfolio, and direct contact channels.

> _"We don't just plan events — we create unforgettable experiences."_

### Core Features

- **🎠 Dynamic Hero Section** — Full-screen animated image carousel with `AnimatePresence` transitions, dot indicators, and a smooth crossfade every 4 seconds
- **📐 Event Planning Wizard** — Multi-step interactive form to capture event requirements, guest count, budget, date preferences, and service selections
- **🖼️ Masonry Photo Gallery** — Responsive masonry grid with category filtering using React Responsive Masonry and a lightbox viewer
- **💬 Testimonials** — Embla Carousel-powered testimonial slider with client quotes and ratings
- **🏛️ Venue Partners** — Curated showcase of premium venue partners with interactive cards
- **❓ Accordion FAQ** — Fully accessible Radix UI accordion with smooth height animations
- **📞 WhatsApp CTA** — Floating WhatsApp button for instant business communication
- **🗺️ Google Maps Embed** — Live embedded map showing company location in Narsapur, Telangana
- **🌐 Multi-Page SPA** — Eight distinct service pages with consistent branding and layout

## ⚡ Getting Started

### Prerequisites

Ensure the following are installed on your machine:

```bash
node >= 18.0.0
npm >= 9.0.0
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/VarshaPatil18/Evently.git

# 2. Navigate into the project directory
cd Evently

# 3. Install all dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be available at **http://localhost:5173**

### Build for Production

```bash
# Create an optimized production build
npm run build

# Preview the production build locally
npm run preview
```

## 🎨 Design System

The UI follows a rich, warm color palette inspired by traditional Indian celebrations:

| Token | Hex | Usage |
|-------|-----|-------|
| **Primary** | `#6B2C2C` | Buttons, icons, accents, brand color |
| **Primary Dark** | `#5A2424` | Button hover states |
| **Background** | `#F5F1E8` | Warm off-white sections, navbar |
| **Text Primary** | `#2C2C2C` | Headings, strong text |
| **Text Secondary** | `#4A4A4A` | Body copy, subtitles |
| **Surface** | `#FFFFFF` | Cards, modal surfaces |

**Typography:** Serif fonts for headings (elegance), system sans-serif for body (readability)

**Spacing Scale:** Tailwind CSS v4 default scale with consistent `py-20` section padding

## 📱 Responsive Design

Evently is built **mobile-first** and tested across all breakpoints:

| Breakpoint | Width | Layout |
|------------|-------|--------|
| **Mobile** | `< 768px` | Single column, stacked sections |
| **Tablet** | `768px – 1024px` | 2-column grid layouts |
| **Desktop** | `> 1024px` | Full multi-column layouts (up to 5 cols) |

Key responsive behaviors:
- Pill-shaped fixed navbar collapses gracefully on mobile
- Hero text scales from `text-4xl` → `text-6xl`
- Services grid adapts: `grid-cols-2` → `grid-cols-5`
- How We Work timeline switches from vertical to horizontal zigzag layout
